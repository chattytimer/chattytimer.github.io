# Chatty Utility - Student & Teacher Resource Hub

Welcome to **Chatty Utility**, a comprehensive collection of free, ad-free web tools designed specifically for students and teachers at Chatfield Senior High School.

## 🚀 Quick Start

Visit the landing page by opening `index.html` in your browser, or access it online at your GitHub Pages URL.

## 📚 What's Included?

### Academic Tools
- **Grade Calculator** - Calculate weighted grades and GPA
- **Unit Converter** - Convert measurements for science and math
- **Percentage Calculator** - Discounts, tips, taxes, and more
- **Geometry Visualizer** - Visualize shapes and calculate properties
- **Periodic Table** - Interactive periodic table of elements
- **Formula Reference** - Physics, Chemistry, and Biology formulas
- **Citation Generator** - Create MLA, APA, and Chicago citations
- **Essay Outline Generator** - Structure your essays effectively
- **Text Stats Counter** - Analyze your writing (word count, reading time, etc.)
- **Dictionary & Thesaurus** - Look up words and find synonyms
- **Calculator with History** - Scientific calculator with saved calculations
- **Time Zone Converter** - Convert times across time zones

### Productivity Tools
- **Schedule Timer** - Track your school schedule
- **Assignment Tracker** - Keep track of all your assignments and deadlines
- **Pomodoro Timer** - Focus timer with customizable work/break intervals
- **To-Do List** - Simple task management
- **Habit Tracker** - Build and track daily habits
- **QR Code Generator** - Create QR codes for study materials

## ✨ Key Features

✓ **No Ads** - Completely ad-free experience  
✓ **No Account Required** - No login needed  
✓ **Offline Capable** - Works without internet (except QR code generation)  
✓ **Data Privacy** - All data stored locally in your browser  
✓ **Mobile Friendly** - Works on phones, tablets, and computers  
✓ **Fast & Lightweight** - Loads quickly even on slow connections  

## 🎯 How to Use

1. **From the Landing Page**: Click on a subject category (Math, Science, Social Studies, English) or the Utilities dropdown
2. **Direct Links**: Each utility has its own folder and index.html file
3. **Back Navigation**: All utilities have a "Back to Home" button to return to the landing page

## 🔧 Technical Details

- **Technology**: Pure HTML5, CSS3, and Vanilla JavaScript
- **Storage**: Browser localStorage for data persistence
- **Hosting**: GitHub Pages (static site)
- **No Backend Required**: Fully client-side applications

## 💾 Data Storage

All tools that save data use your browser's localStorage. This means:
- Your data stays private on your device
- Data persists between sessions
- Clearing browser cache will clear saved data
- Can be synced across tabs on the same device

1. **Grade Calculator** - Use for weighted grades to predict your final grades
